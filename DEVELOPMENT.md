# Бизнес Империя

## Исходник и запуск

`game_dev.html` — основной исходник игры: HTML, CSS и JavaScript в одном файле. Начальная версия перенесена без изменений из `game_v17.html` проекта «Создание игры».

Для запуска скачайте репозиторий и откройте `game_dev.html` в браузере. Сборка не требуется.

## Следующие изменения

1. Получите актуальную версию репозитория и создайте ветку для задачи.
2. Изменяйте `game_dev.html`, не создавая копии с номерами версий.
3. Проверьте синтаксис JavaScript и затронутые функции в браузере.
4. Сохраните завершённое изменение коммитом с понятным описанием.
5. Отправьте ветку в GitHub и откройте pull request в `main`.

История Git хранит предыдущие версии и позволяет сравнить или вернуть изменения. Перед заменой уже существующих файлов проверяйте их содержимое. Не используйте принудительную отправку и не переписывайте историю без согласования.

Начальная версия v17 не включает более поздние изменения киоска из DEV #3. Их следует реализовывать отдельными коммитами.
